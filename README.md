This is a prototype of an turn-based RPG. You will fight a Pokemon inspired gym battle (5v5)

I have implemented the following features:
  - A elemental system where types are effective/weak against other types 
  - A skillpoint system where in order to use skills, points are required 
  - You can gain points through normal attacks and using skills deducts one point 
  - A energy system where energy is gained through skills and normal attacks 
  - Once enough energy is gained you can unleash a powerful ultimate attack
